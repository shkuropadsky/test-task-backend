# Glossary
---

## Понятия
- **Запрос Статистики** (**StatQuery**) - задача формирования "пользовательской статистики" (симуляция). Имеет уникальный идентификатор (`Guid`).

## HTTP  
- **Регистрация Запроса** - `POST /report/user_statistics` - возвращает *Идентификатор Запроса*
- **Проверка Запроса**  - `GET /report/info` - использует *Идентификатор Запроса* как параметр

## Идентификаторы
- **Идентификатор Запроса** - `Guid`, генерируемый системой при регистрации *Запроса Статистики*. В JSON-результатах *Проверки Запроса* - параметр `query`.
