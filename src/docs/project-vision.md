# Project Vision
---

## Что
Выполняем тестовое задание на вакансию Backend-разработчика

## Для кого
Техническим специалистам - для Code Review

## Позиционирование
Продемонстрировать навыки проектирования архитектуры и програмной реализации.
От себя: по возможности - реализация подхода EverythingAsCode.

## Ключевые функции
Обработка HTTP-запросов.
Реализация бизнес-логики.
Имитация длительного выполнения задач (асинхронные ответы с искусственной задержкой).
Работа с базами данных.
Различные способы и виды тестирования.

## Нефункциональные требования
.NET, WebAPI, HTTP REST API, ORM, миграции, тесты
