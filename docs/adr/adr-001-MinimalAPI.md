# ADR-001. MinimalAPI
## Контекст
По общим требованиям тестового задания необходимо использовать .NET и WebAPI.
## Решение
В начале разработки вместо контроллеров будем использовать MinimalAPI.
## Последствия
Это позволит компактнее реализовать основные эндпоинты и настроить логирование и тестирование.
