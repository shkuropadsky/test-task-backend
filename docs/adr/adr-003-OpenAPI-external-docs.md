# ADR-003. OpenAPI External Docs (Json and Scalar UI)
## Контекст
Требования тестового задания включают описание необходимого для реализации API.
Необходимо обеспечить доступ к описанию фактически реализованного API.
## Решение
1. Атогенерация схемы фактически реализованного API - `{host}/openapi/v1.json`
2. Интерактивный UI для тестирования API - `{host}/scalar/v1`
## Последствия
Можно использовать новые возможности как для ручного, так и для автоматизированного внешнего тестирования.
