# ADR-004. Logging (Serilog)
## Контекст
Требования предполагают реализацию ответов с искусственной задержкой.
Необходимо обеспечить контроль за ходом обработки процесса выполнения запроса.
## Решение
1. Структурированное логирование
2. Стандартное логирование HTTP-запросов (см. `"HttpLoggingMiddleware": "Warning"`)
3. Использование Serilog (`docker-compose.yaml`)
## Последствия
Можно собирать информацию о первом запросе и проверках статуса выполнения запроса в одном месте, в виде одной сводки.
