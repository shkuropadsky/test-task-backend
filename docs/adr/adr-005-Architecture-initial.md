# ADR-005. Architecture (initial)
## Контекст
Задание простое, но нужно заложить правильную архитектуру.
Начальное требование - реализация API ([`req-001-Http-requests.md`](..\specs\requirements\req-001-Http-requests.md)).
## Решение
1. Всё будет в рамках одного проекта `.csproj`
2. Endpoints, Application, Domain - для начала. Хранение данных пока не используем.
## Последствия
Заложили структуру, которая позволяет решить текущую актуальную задачу и при этом может быть расширена в будущем.
